# Ferramenta-de-Controle-de-Investimentos-com-Excel
Projeto desenvolvido no desafio da DIO com foco na criação de uma planilha em Excel para simulação de investimentos em fundos imobiliários. A ferramenta automatiza cálculos de aportes, patrimônio acumulado e dividendos mensais, auxiliando na tomada de decisões financeiras.
